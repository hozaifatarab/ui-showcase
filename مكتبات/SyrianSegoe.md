## 📌 ما هو؟

**SyrianSegoe** — أداة **تغيير خط النظام** في Windows (Next-Gen System Font Setting Tool).
تستبدل خط **Segoe UI** الافتراضي بنظام كامل بخط مخصص، عبر **توليد نسخة معدّلة من الخط تحاكي Segoe UI** (باستخدام FontForge). لأن النظام يتعرف على الخط كما لو أنه الأصلي، يتحقق **تطابق UI كامل** دون كسر مكوّنات النظام.

> المشكلة التي يحلّها: مكوّنات Windows الحديثة (UWP، قائمة ابدأ، شريط المهام) تطلب خط "Segoe UI" بالاسم وتتجاهل استبدالات Registry (`FontSubstitutes`)، فينتج UI متضارب. SyrianSegoe يتجاوز ذلك بتصحيح ملفات الخط مباشرة.

## ✨ الميزات
- **استبدال حقيقي على مستوى النظام:** يعمل على UWP، شريط مهام ويندوز 11، الإعدادات، شاشات الترحيب وتسجيل الدخول.
- **Font Resizer** — مقياس حجم الخط.
- **دعم خطوط UI العربية:** يمزج خطاً لاتينياً أساسياً مع خط عربي ثانوي لواجهة ثنائية اللغة مثالية.
- **اختيار ذكي:** يكتشف تلقائياً كل أوزان الخط عند اختيار الملف أو من الخطوط المثبتة حسب اسم السجل.
- **نسخ احتياطي واستعادة مدمج:** نسخة تلقائية من خطوط Segoe الأصلية + استعادة بضغطة واحدة.
- **واجهة متعددة اللغات:** إنجليزي · تركي · عربي.

## 🔠 الخطوط المدعومة
- كل خطوط الـ UI مدعومة، **بما فيها Variable Fonts**.
- إن نقصت أوزان ثابتة (Light / SemiBold...)، يولّدها البرنامج تلقائياً.

## 🚀 الاستخدام
1. **شغّل كمسؤول (Administrator)** — مطلوب لتعديل خطوط النظام.
2. **اختر الخط اللاتيني:** تصفح لخط Regular — التطبيق يبحث تلقائياً عن Bold و Black في نفس المجلد.
3. **اختر الخط العربي (اختياري):** إن استخدمت عربية في النظام أو لوحة المفاتيح.
4. **اضغط Build & Apply** (إن لم يكن FontForge مثبتاً، يعرض تثبيته عبر `winget`).
5. **أعد تشغيل الجهاز (Reboot)** ليُطبَّق التغيير على النظام كله.
   - للتراجع: افتح التطبيق واضغط **Restore Original Fonts**.

## 🛠️ البناء من المصدر
```bash
git clone https://github.com/SyrianTurk/SyrianSegoe.git
cd SyrianSegoe
pip install -r src/requirements.txt
python -m PyInstaller --noconfirm --onefile --windowed \
  --icon "src/logo.ico" \
  --add-data "src/engine.py;." \
  --add-data "src/SyrianSegoe_Banner.png;." \
  --add-data "src/SyrianSegoe_Banner_Light.png;." \
  --add-data "src/logo.ico;." \
  "src/app.py"
```
